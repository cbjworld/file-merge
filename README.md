# 파일 수합

엑셀(.xlsx)과 한글(.hwpx) 파일을 순서대로 하나로 합치는 정적 웹페이지입니다. 모든 처리는 브라우저 안에서만 이뤄지며 파일은 서버로 전송되지 않습니다. 라이브러리(JSZip, ExcelJS)를 `vendor/`에 포함해 외부 CDN 없이 동작합니다(내부망 가능).

- 엑셀: 첫 파일 서식 유지, 헤더/성명 열 자동 감지, 같은 순서의 시트끼리 병합
- HWPX: 파일마다 원본 서식을 유지한 채 뒤에 이어붙임

`index.html`을 정적 호스팅(GitHub Pages, Vercel 등)에 올리면 됩니다.
