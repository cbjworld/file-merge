# 파일 수합기 · File Merge

**여러 엑셀·한글 문서를, 브라우저에서 하나로.**

같은 양식으로 받은 엑셀 명단이나 여러 HWPX 문서를 모을 때 사용하는 파일 수합 도구입니다. 설치와 회원가입 없이 사용할 수 있으며, 선택한 문서의 내용은 서버로 전송되지 않습니다.

### [→ 지금 사용하기](https://cbjworld.github.io/file-merge/)

유용하게 쓰셨다면 저장소 오른쪽 위 **⭐ Star**로 응원해 주세요. 오류 제보와 개선 제안도 환영합니다.

## 어떤 작업을 할 수 있나요?

| 형식 | 수합 방식 |
| --- | --- |
| 엑셀 `.xlsx` | 첫 파일을 기준으로, 성명·이름 열을 찾아 같은 항목의 빈 값을 채우고 새 항목을 추가합니다. |
| 한글 `.hwpx` | 파일 순서대로 문서를 이어 붙입니다. 원본 서식을 유지하도록 병합합니다. |

- 엑셀의 헤더와 성명 열을 자동으로 찾습니다.
- 여러 시트가 있으면 **같은 순서의 시트끼리** 합칩니다.
- 엑셀 값이 충돌하면 기존 값을 유지하고 경고를 표시합니다.
- 파일 순서를 바꿔 기준 파일과 병합 순서를 정할 수 있습니다.
- JSZip과 ExcelJS를 포함해 외부 CDN에 의존하지 않습니다.

## 1분 사용법

1. [수합기 열기](https://cbjworld.github.io/file-merge/)
2. **엑셀** 또는 **한글(HWPX)** 선택
3. 같은 형식의 파일 **2개 이상** 추가
4. 파일 순서 확인 — 엑셀은 첫 번째 파일이 기준입니다.
5. **합치기**를 누르고 결과 파일 다운로드

완료 후 경고와 진행 로그를 확인하고, 결과 파일을 엑셀 또는 한글에서 열어 확인하세요.

## 사용 예시

### 엑셀 명단의 빈 값 채우기

| 파일 | 성명 | 연락처 |
| --- | --- | --- |
| 기준 파일 | 홍길동 | (비어 있음) |
| 두 번째 파일 | 홍길동 | 010-0000-0000 |
| 두 번째 파일 | 김수합 | 010-1111-1111 |

합친 결과에는 홍길동의 연락처가 채워지고, 기준 파일에 없던 김수합이 추가됩니다. 같은 성명의 값이 서로 다르면 첫 파일의 값을 유지하고 경고를 표시합니다.

### HWPX 문서 이어 붙이기

`문서 A.hwpx` → `문서 B.hwpx` → `문서 C.hwpx`

선택한 순서로 하나의 HWPX 문서로 합칩니다.

## 지원 형식과 주의사항

- 지원: **`.xlsx`, `.hwpx`**
- `.xls`와 `.hwp`는 직접 지원하지 않습니다. 각각 XLSX와 HWPX로 저장한 뒤 사용하세요.
- 엑셀은 같은 양식과 같은 시트 순서의 파일을 사용하면 결과를 확인하기 쉽습니다.
- 동일한 성명·이름을 같은 항목으로 취급하므로 **동명이인은 결과를 따로 확인**하세요.
- 새 항목은 시트 아래에 추가될 수 있으며, 기존 합계 수식 범위에 자동으로 포함되지 않을 수 있습니다.
- 형식이 맞지 않는 파일이나 시트는 제외될 수 있습니다. 경고와 진행 로그를 확인하세요.
- 복잡한 서식과 큰 파일은 처리 결과를 확인해야 합니다. 원본 파일을 보관하고 결과 문서의 내용·서식·합계 등을 확인하세요.

## 문서는 어디에서 처리되나요?

파일 읽기와 병합은 **사용자의 브라우저 안에서** 실행됩니다. 선택한 문서 내용을 업로드하는 서버 API는 사용하지 않습니다. 웹페이지 접속 자체는 GitHub Pages를 통해 이루어집니다.

## 로컬에서 실행하기

1. 이 저장소를 ZIP으로 다운로드하거나 복제합니다.
2. `index.html`, `core.js`, `vendor/`를 같은 폴더 구조로 유지합니다.
3. `index.html`을 브라우저에서 엽니다.

정적 웹페이지이므로 별도의 앱 서버나 빌드 과정이 필요하지 않습니다.

**English:** A browser-based tool for merging Excel (.xlsx) and Korean HWPX documents. Excel merging fills missing values and appends new entries using a detected name column; HWPX documents are joined in order. Selected document contents are processed locally in the browser. No installation or sign-up is required.
